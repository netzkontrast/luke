# Aufnahmen, wie sie kamen

Die Dateien hier sind die unbearbeiteten Aufnahmen der Papierarbeiten, so wie Luke sie
geschickt hat: Blatt auf schwarzem Grund fotografiert, Instagram-Zuschnitt 4:5.

Was in `assets/img/` liegt, ist daraus abgeleitet: auf das Papier zugeschnitten und der
Papierton auf reines Weiß gezogen, damit `mix-blend-mode: multiply` auf der weißen Seite
nur die Zeichnung stehen lässt. Der Weg dorthin steht in der README unter „Aufnahmen von
Papierarbeiten vorbereiten“.

Dieser Ordner bleibt im Repository, damit ein anderer Zuschnitt später noch möglich ist.
Ausgeliefert wird er nicht (siehe `.vercelignore`).

Dazu zwei Grafiken, die ebenfalls beschnitten wurden: Bei beiden lag das eigentliche Bild in
einem Rand, der weg musste. Die übrigen drei Grafiken sind unbeschnitten übernommen und
stehen deshalb nicht hier.
