# Aufnahmen, wie sie kamen

Hier liegt jede Aufnahme so, wie Luke sie geschickt hat. Was in `assets/img/` steht, ist
daraus abgeleitet: zugeschnitten, im Papierton auf Weiß gezogen, kleiner gerechnet. Der
Weg dorthin steht in der README unter „Aufnahmen von Papierarbeiten vorbereiten".

Der Ordner bleibt im Repository, damit ein anderer Zuschnitt oder eine größere Fassung
später noch möglich ist. Ausgeliefert wird er nicht (siehe `.vercelignore`).
